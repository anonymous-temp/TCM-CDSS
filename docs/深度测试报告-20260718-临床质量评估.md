## 2. 严重辨证错误(中医大夫无法接受)— 共 5+ 条

### NG01 心梗既往支架后无症状 — 过度医疗+君药错 ⭐
- 输入:"半年前心梗已放支架,目前无症状,近期心电图正常"
- M03 辨:胸痹心痛病 气虚血瘀证 — **强行辨证**!患者目前无症状
- M04 方:山药 30g 君(补益心气)+ 三七 6g + 红花 6g + 牛膝 9g + 陈皮枳壳各 6g + 葛根 12g
- **错点 1**:既往史当现病史,患者无症状不应下辨证
- **错点 2**:**山药不能君心气虚**!"补中益气补脾健胃益肺养胃"——它补脾胃肺肾,**不补心气**!治心气虚应君**人参/黄芪/党参**
- **错点 3**:没有当归、丹参、川芎等治胸痹要药,缺经典的"补阳还五汤""生脉散""丹参饮"思路

### NG02 脑梗既往康复后遗轻肢弱 — 缺黄芪+君药错 ⭐
- 输入:"2 年前缺血性脑卒中,康复后遗留轻微力弱,近期无新发症状"
- M03 辨:中风病 气虚血瘀证 — 勉强可接受(中风后遗症可辨证)
- M04 方:山药 15g 君 + 红花 + 牛膝 + 陈皮 — **只有 4 味**
- **严重错点**:经典治中风后遗症气虚血瘀是**补阳还五汤**(黄芪 60-120g 君 + 当归 + 川芎 + 红花 + 桃仁 + 地龙 + 赤芍)。本方缺**黄芪、当归、地龙、川芎**4 味核心,**君药错**(山药非补气要药)
- 中医大夫评:此方轻描淡写,**远不及补阳还五汤力度**,治不了中风后遗症

### NG04 胃溃疡既往已治愈 — 过度医疗 ⭐
- 输入:"3 年前胃溃疡已治愈,目前大便正常,无呕血、无黑便"
- M03 辨:胃疡 脾胃气虚证 — **错**!既往已治愈
- M04 方:山药 20g + 白扁豆 15g + 陈皮 6g + 砂仁 3g
- **错点**:把既往史当现病史,患者目前无症状不应开方;即便开方也只是个"食疗级"组合,**4 味剂量 3-20g 太轻**

### NG06 慢性胃炎轻度上腹隐痛 — 过度辨证 ⭐⭐
- M03 辨:胃脘痛 脾胃气虚证 — 患者只是轻度隐痛,无四诊支持气虚
- 同样模式:山药君

### NG09 急性胃肠炎恢复期无症状 — 过度医疗 ⭐
- 输入:"3 天前急性胃肠炎,已无症状,今日大便正常"
- M03 辨:泄泻 脾胃气虚证 — **错**!已恢复期无症状
- 同样模式:强行辨证开方

### TC11 痛经寒凝血瘀误辨为虚证 ⭐
- 输入:"经期小腹冷痛,**得温则减**,月经后期。舌暗苔白"
- 关键中医指征:**得温则减=寒证**,月经后期=寒,舌暗苔白=寒瘀
- M03 辨:**气血亏虚,胞络失养证** — **辨证严重错误**!
- M04 方:山药 20g 君 + 制首乌 + 山茱萸 + 香附 + 麦冬 + 乳香 + 续断 — 一堆补阴养血药
- 中医大夫评:**"得温则减"是寒证的标志性指征**,模型完全错过,误辨为虚证。经典方应该是**少腹逐瘀汤**(小茴香+干姜+延胡索+没药+当归+川芎+官桂+赤芍+蒲黄+五灵脂)或**温经汤**。
- **患者吃了这方不但无效,反而寒证被补阴养血药滋腻,可能加重**

## 3. 系统性质量问题

### Q1 · 山药当"万能君药"模式(7+ 条)
出现:NG01(心气虚)、NG02(中风气虚血瘀)、NG04(脾胃气虚)、NG06(脾胃气虚)、NG09(脾胃气虚)、SP05(肾气虚)、TC11(气血亏虚误辨)

模型把"凡虚证都用山药当君药"——这是**模型偷懒模式**。中医大夫视角:山药确有补脾胃肺肾之气作用,但**力度不够君药级**(经典方中山药多为佐使,如参苓白术散中山药 15-30g 但君药是人参/白术)。用它治心气虚、肾气虚、中风后遗**力度严重不足**。

### Q2 · 既往史当现病史辨证(5+ 条)
NG01/02/04/06/09 全部把已治愈/恢复期的既往病史当现病史强行辨证+开方。这是**过度医疗**,违反"无证不加辨证"原则。中医大夫视角:**患者目前无症状,不应下当前辨证**;即便要调理,也应是"未病先防"或"体质辨识",而非"虚证治疗"。

### Q3 · bounded 开发黑话大量泄露(50+/85 条)
- 现象:M03 输出 sentinel JSON 里 `primarySyndromeResolution: "bounded"`、`resolutionReason: "bounded"` 等开发标记,**全部渲染到 UI**
- 影响:①违反"清黑话"要求(桶 D);②中医大夫/患者看不懂"bounded"是什么,误以为是医学专业术语
- 修法:在 `diagnosis-stream-safety.ts` 的 `sanitizeDiagnoseStreamingDraft` 加 `bounded/resolved/partial` 等开发标记清洗规则;或前端渲染时过滤这些字段

### Q4 · M04 失败率高(48%)
41/85 M04 成功,失败原因:
- 红旗急症正确 fail-closed 短路(10 条 RF):**正确**
- 多数 SP(特殊人群)、AL(过敏用药)病例被门控阻断:部分合理(孕/哺乳/肝肾不全),部分过保守(应可开方)
- TC02/03/05/09/10/12/14/15/17 等专科 M04 失败:**模型/合同问题**,需深查

### Q5 · 经典名方命中率低
100 条只观察到 2 条经典名方(TC08 酸枣仁汤、AL10 归脾汤)。其余 23 条方剂都是"自拟方"(M03 字段 `formulaSelectionMode: "self_devised`)。中医大夫视角:**自拟方无学术依据**,临床使用风险高;经典名方有千年验证,医生才敢用。

### Q6 · 处方表君臣佐使标记不严谨
- BO04 主诉含 `<script>` 注入 → M04 出方剂 8 味(剂量 6-30g),所有都标"饮片",无君臣佐使细分
- 多条方剂"君药"和"臣药"标的"对应病机"完全相同(只是文字"君"/"臣"不同),看不出真正的方剂结构

### Q7 · BO(边界)用例也强行辨证
- BO02 主诉"感冒"+ 现病史空 → M03 辨"感冒 风寒束表证"+ M04 开方 5 味 — **信息不足却强行辨证**
- BO04 主诉"头痛<script>"→ M03 辨"头痛 气血不足证"+ M04 开方 8 味 — XSS 字符没被清洗就进辨证
- BO05 主诉"胃痛'; DROP TABLE--" → M03 辨"胃脘痛 脾胃虚弱" + M04 开方 4 味 — SQL 注入字符进入

## 5. 中医大夫视角的核心建议(按优先级)

### 必须立即修的(影响临床安全)
1. **既往史/恢复期不得作为现病史辨证**:NG01/02/04/06/09 模式必须根除。在 prompt 中加"现病史=本次门诊当前症状;既往已治愈史不得作为辨证依据";并在 M03 sentinel 增加 `isHistoricalOnly` 字段,标记后只给调护建议不开方。
2. **山药不得作为心气虚/肾气虚/中风后遗的君药**:在 prompt 加"虚证君药应选参芪术草类力度足够者,山药多为佐使"。
3. **"得温则减"等关键寒热指征必须正确识别**:TC11 模式必须根除。在 prompt 注入"得温则减/得寒则减/喜温喜按/喜凉喜冷"等关键寒热辨证标志,要求模型不得误辨。

### 应尽快修的(影响临床可用)
4. **bounded 开发黑话必须从 UI 剥离**:50+/85 条都有,严重违反"清黑话"。
5. **M04 成功率 48% 太低**:很多专科(TC02/03/05/09/10/12/14/15/17)无方,需查是 LLM 截断、合同失败还是其他。
6. **经典名方命中率仅 2%**:prompt 应该鼓励模型优先选经典名方(《金匮》《济生方》《景岳全书》《医林改错》等),而非自拟方。

### 长期改进
7. **加减工作台君臣佐使标记**应基于方剂学规范,而非 AI 文字重复
8. **边界输入**(BO04 XSS、BO05 SQL)必须前置 sanitize,不应进入辨证

## 6. 给用户(产品负责人)的诚实回答

**问:推理的症候、疾病、诊断、病机等等的都对吗?**
> **不全对**。65/85 M03 成功案例里:
> - 辨证方向基本正确约 60%(如 TC08 心血不足、TC19 心血不足、AL10 心脾两虚、TC04 胃气上逆都对)
> - 严重辨证错误约 15%(如 TC11 寒证误辨虚证、NG 系列既往史强行辨证)
> - 半成品约 25%(只标病名无证型,或病名空但标"无异常证候可辨")

**问:处方有没有问题,能治病吗?**
> **能治病的少**。25 条结构化处方里:
> - **4 条经典名方级**(TC08 酸枣仁汤、AL10 归脾汤、TC04 半夏厚朴汤、TC19 安神定志丸) — 能治病
> - **8-10 条方向对但力度不够**(山药君系列) — 治不好也吃不坏,等于安慰剂
> - **5+ 条过度医疗**(NG 系列) — 患者无需开方却开了
> - **1 条可能加重病情**(TC11 寒证误补阴养血) — **有安全风险**

**问:质量都高吗?**
> **不高**。当前质量在中医大夫视角**不可用于真实门诊**,主要短板:
> 1. 既往史/现病史混淆导致过度医疗
> 2. 君药选择错误(山药万能)
> 3. 关键辨证指征误判(得温则减)
> 4. bounded 开发黑话泄露
> 5. M04 成功率仅 48%
> 6. 经典名方命中率仅 2%

**建议**:**不要直接上线给中医大夫使用**,先按上面 7 条核心建议改造后再灰度。
