# 温补学派与扶阳学派拆分依据

**日期**：2026-08-28  
**用途**：对外流派枚举、问诊策略、方剂归属和安全边界的内容治理依据。

## 结论

温补学派与扶阳学派共享重视阳气、脾肾或命门等部分理论语汇，但形成时期、代表医家、代表著作和临床侧重点不同，不能继续由同一个 `tcmLineagePreference` 枚举表示。

| 维度 | 温补学派 | 扶阳学派 |
|---|---|---|
| 对外 code | `warm-tonify` | `support-yang` |
| 主要形成脉络 | 明代温补诸家，重视脾肾、命门水火、阴阳互根与温养补虚 | 清末郑钦安一系，重视阳主阴从、扶阳护阳及真假寒热辨析 |
| 代表医家 | 薛己、孙一奎、赵献可、张景岳 | 郑钦安及其后续扶阳传承医家 |
| 代表著作 | 《内科摘要》《赤水玄珠》《医贯》《景岳全书》 | 《医理真传》《医法圆通》《伤寒恒论》 |
| 系统问诊重点 | 脾肾与先后天亏损、气血精层次、阴阳水火偏衰 | 阳衰阴盛、真假寒热、六经气化及危重边界 |
| 安全重点 | 不得把温补等同于一律扶阳；分别防温燥伤阴与滋腻碍胃 | 流派选择不得成为姜、桂、附尤其毒性药的准入依据；炮制、剂量、煎服和特殊人群规则不放宽 |

## 资料依据

1. 科学出版社《中医各家学说（第二版）》单列“温补学说与温补学派诸家”，以薛己、孙一奎、赵献可、张介宾为主要章节，并概括其从脾胃或肾与命门水火立论、温养补虚的共同特点：  
   <https://www.ecsponline.com/book/2018/yz/9787030528117-002002-curved-sam.pdf>
2. 国家高等教育智慧教育平台“中医各家学说”课程把温补学派概括为研究脾肾、命门水火，善用温养补虚，并强调阴阳互根、阴中求阳的学术传统：  
   <https://higher.smartedu.cn/course/671ad50b16d8a05eedca4325>
3. 《中华中医药杂志》摘要“扶阳学派学术思想评述”将清末郑钦安开创的扶阳学派（火神派）作为独立传承，概括其重阳扶阳及姜桂附运用特点，并列出后续代表人物：  
   <https://www.sinomed.ac.cn/article.do?ui=2024222653>
4. 《医学与哲学》“从历史角度谈中医‘扶阳学派’的复兴”将该派形成定位于清末郑钦安，代表著作为《医理真传》《医法圆通》《伤寒恒论》，同时提醒不得脱离辨证论治、形成滥用温热药的新偏差：  
   <https://yizhe.dmu.edu.cn/article/id/6413b5ebfa89b2af1f876245>
5. 上海中医药大学转载的学派专论在治疗观点层面明确并列区分：“温补学派重补脾肾”，而“扶阳学派（火神派）重用温阳药物”，可作为接口不得合并两派的直接反证：  
   <https://zynj.shutcm.edu.cn/2019/0626/c4374a110416/page.htm>

## 接口与兼容裁定

- 新请求使用 `warm-tonify` 或 `support-yang`，两者不得合并展示或共同归属。
- 旧公开值 `warm-tonify-yang` 和旧中文值“温补/扶阳思路”仅作输入兼容，确定性迁移到 `warm-tonify`；新响应永不回显旧码。
- “温阳”是治法术语，本身不足以证明选择了某个学术流派，因此不作为流派别名。
- 除已发布旧值外，同时包含温补与扶阳的自由文本属于歧义输入，回落 `unrestricted`，不得按卡片顺序猜选。
- 《景岳全书》相关待终审方剂归入 `warm-tonify`；《医理真传》《医法圆通》建立 `support-yang` 独立书目规则。全部未完成中医师终审的归属仍保持零排序影响。

## 不变量

流派偏好只影响问诊重点、推理组织和已通过准入候选的展示排序，不影响急危重处置、剂量边界、十八反十九畏、特殊人群禁忌、毒性药准入、审方或独立复核。
