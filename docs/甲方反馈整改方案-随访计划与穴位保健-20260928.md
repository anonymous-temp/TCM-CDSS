## 一、随访计划面向患者

### 1.1 问题核查

**（1）内容写给了医生。** 线上真实输出（脾胃气虚证·便溏 3 月）：

| 栏目 | 整改前内容（节选） | 读者 |
|---|---|---|
| 首次复诊时间 | 完成7剂（7日）后复诊；出现不适或症状加重时提前复诊 | 勉强可读 |
| 复诊评估重点 | 重点复评大便溏泄的次数与性状……脉细弱有无起色，以判断**脾气来复**与否 | 医生 |
| 疗效评价标准 | ……即判为这一轮**健脾益气渗湿**有效 | 医生 |
| 无效或加重的处置预案 | **不自动沿用候选方案，由医生复评诊断、辨证与处方风险** | 系统/医生 |
| 整体状态复评表 | 食欲、餐量及进食后不适**较首诊如何变化？**；「……不替代**处方后安全审方**」 | 医生问诊单 |
| 随访时间轴·动作 | **面诊复评**……**据脾气来复程度决定是否调方续进** | 医生 |

原因：M05 随访撰写提示词明确要求「复诊重点是给医生的检查清单」，确定性模板句也是写给医生/系统的边界声明。患者真正需要的「什么时候复诊、出现什么提前来、出现什么立即去急诊」散落在时间轴的触发条件里，没有集中成句。

**（2）关联缺陷：页面与 HIS 写回不一致，且就医指征会被删掉。** 线上同一次调用（风热犯肺证·咳嗽）：

| 栏目 | HIS 写回（未改写） | 医生页面（被改写） |
|---|---|---|
| 复诊评估重点 | 复诊重点评估咳嗽频次与程度……有无新出现恶寒发热或汗出…… | **病历已记录咽干、咳嗽阳性；病历已记录否认发热。** |
| 疗效评价标准 | 咳嗽明显减少……无新发恶寒发热……视为本轮有效。 | **病历已记录咽干、咳嗽阳性；病历已记录否认发热，视为本轮有效。** |

M04 注意事项也出现过「**病历已记录否认胸痛、呼吸困难、气促，应立即急诊就医**」「服药期间出现发热不退或痰中带血，应立即就医」→「**病历尚未确认发热是否存在，应立即就医**」（「痰中带血」这条就医指征被删）。

原因：服务端有一道「接地校验」，用来防止模型编造病历里没有的症状。它把「有无发热」「无改善」「服药期间出现……」这类**对将来的提醒**误当成对当前病历的陈述，整句替换成病历状态句。医生页面这一路做了这道校验，HIS 与处方后审两路没做，于是三处内容不一致。以上改写已在本地离线逐字复现。

### 1.2 整改措施（已完成）

栏目名全部保持不变（首次复诊时间 / 复诊评估重点 / 疗效评价标准 / 安全性观察 / 注意事项 / 无效或加重的处置预案 / 整体状态复评 / 生活管理 / 随访时间轴），内容一律改为**写给患者本人**。

| 栏目 | 整改后 | 生成方式 |
|---|---|---|
| 首次复诊时间 | 「请在服完7剂药后（约7天后）复诊；如有不适或症状加重，请提前复诊。」 | 确定性：按处方剂数/疗程计算，与处方煎服法同源；随访时间轴第一条与之逐字相同 |
| 复诊评估重点 | 「复诊时医生会重点了解大便每天几次、是否成形，腹胀和胃口……并查看舌象和脉象；请您服药期间留意并记下这些变化。」 | 模型按本例撰写；模型不可用时回落同口吻模板 |
| 疗效评价标准 | 「大便逐渐成形、次数减少，腹胀减轻、胃口变好、精神体力恢复，说明治疗有效。」 | 同上 |
| 安全性观察 | 「服药期间请留意：……；如出现上述情况，请及时复诊。」 | 确定性：来自处方安全核对，只增不减 |
| 无效或加重的处置预案 | 「服药后症状没有好转、反而加重，或出现新的不适，请及时回门诊复诊……请不要自行加减或更换药物。如出现皮疹、瘙痒、胸闷气短等过敏或明显不适，请暂停服药并及时就医。**如出现大便带血或发黑、高热不退、剧烈腹痛……，请立即到急诊就医。**」 | 处置句固定；急诊表现由模型按本例病情撰写，未写出时回落通用急症表现（高热不退、胸痛或呼吸困难、神志不清或抽搐、出血），不会空着 |
| 整体状态复评表 | 「入睡快慢、夜里醒几次、是否早醒，醒后精神怎样，和这次就诊时比有没有变化？」；表尾「服药期间请留意以上几方面的变化，复诊时告诉医生……」 | 维度闭集不变，问句改白话 |
| 生活管理 | 本例饮食/作息/情绪/活动的具体做法 +「请不要自行叠加中药或中成药；复诊时请携带正在使用的全部药物（或药盒、药品清单）。」 | 模型撰写 + 固定安全句 |
| 随访时间轴 | 动作写患者要做的事（「电话或线上告诉医生怕冷是否好转、咳嗽是否变得顺畅」）；观察项写患者能自己观察的变化；触发条件写「出现什么提前来」 | 模型撰写；处方安全触发条件只增不减并入第一条 |

配套控制：

1. **写给患者的句子不得出现病历状态句与内部流程词**（「病历已记录/尚未确认」「候选方案」「审方」「复评」「采纳」「辨证」等，有限闭集，内部流程词收入受治理禁述表《患者随访/调护文本禁述表》新增分组，带依据、可审核）。模型写出即整段不采纳、回落模板；M04 注意事项的逐条清洗使用同一张表。
2. **对将来的提醒不再被改写。** 接地校验对条件/疑问/前瞻句（若、如果、一旦、如出现、有无、服药期间、出现……时，有限闭集）从条件词起到句末原样保留；条件词之前的部分和其他句子仍照常纠正对当前病历的错误陈述（如「患者否认便血、黑便，如出现上述情况请立即就医」里前半句的否认若病历没有记录，仍会纠正——这道校验同样作用于辨病辨证与方药正文，不能因为同句后半有「如出现」就整句放行）。该修正同时覆盖 M04 注意事项。
3. **医生页面、处方后审、HIS 写回三处随访内容同源。** 接地校验只作用于处方安全核对文本，不再作用于随访正文。
4. 红旗、无剂量方案、硬剂量边界三条降级路径仍完全确定性，不走模型；「处方安全总评」（最高提示强度、综合风险判断、医生需确认事项）是写给医生的安全结论，不在本次改动范围。

## 二、调护「穴位保健」空缺

### 2.1 问题核查

- 「穴位保健」对应 M04 结构化结果的 `nonPharma.acupointCare`（接口文档已有此字段，类型 string / null）。当前版本服务端在三处把它**固定置为空**，下发给模型的输出结构里也删去了这个字段——**任何病例都不会出现**，不是测试病例没碰上。
- 原因：2026-08 为防止模型自由书写穴位、绕过禁忌核对（妊娠禁用穴、皮肤破损、出血倾向等），规定穴位只能来自受控项目目录。但受控目录只覆盖需医师操作的项目，结果写在「中医非药物方案」项目卡的「穴位/部位」里（线上两例实测：针刺卡给出肾俞、关元、足三里……，耳穴卡给出脾、胃、神门……）。面向患者、可以居家自我保健的穴位，系统里一直没有来源，于是「穴位保健」这一栏始终是空的。
- 现有数据盘点：《经络腧穴学》400 穴目录只有定位、主治和**针刺**操作；22 个非药物项目的 26 个方案模板里，只有耳穴压豆涉及患者自行按压。两者都没有「居家按揉：手法、时长、频次」的口径，不能直接当作患者穴位保健使用。

### 2.3 整改方案

1. **建立受治理的穴位保健清单。** 首批收录上述技术规范中九种体质的保健穴与儿童按月龄方法，每条带来源条目、定位（按 GB/T 12346-2021 逐条核对）、手法、每次时长、每日次数、禁忌人群，由中医师审定签字后生效。只收患者或家属可居家完成的按揉、摩腹、捏脊等手法；艾灸有烫伤风险，默认不收，是否纳入见 2.4。
2. **选穴全程确定性，不交给模型自由书写。** 由已签名的本次证候/病机，经受治理映射表对应到体质类别（如脾胃气虚→气虚质、膀胱湿热→湿热质），再取该类的 1～2 个保健穴；与本例已开出的针刺、耳穴项目卡去重。证候与体质并非一回事，映射表只收中医师认可的对应，对应不上的病例不输出。本环节不调用模型，不增加耗时。
3. **安全过滤（确定性，复用现有判据）。**
   - 妊娠阳性或可疑（复用现有妊娠状态判据）：排除三阴交、合谷、昆仑、至阴及腹部、腰骶部穴位（气海、关元、命门、神阙等），无可替代穴则不输出；
   - 红旗、无剂量方案、硬剂量边界等降级状态：不输出；
   - 儿童按月龄模板输出，6 月龄以下不输出；
   - 每条附固定注意句：饭后 1 小时内、局部皮肤破损或感染处不要按揉；有出血倾向或正在服用抗凝药者先咨询医生；居家保健参考，不能替代治疗。
4. **呈现（字段不变，接口文档不改）。** 写入 M04 调护中已有的「穴位保健」栏（`nonPharma.acupointCare`），患者口吻，例如：「足三里（小腿外侧，膝盖下方约四横指、胫骨外侧约一横指处）：用拇指指腹轻柔按揉，以酸胀为度，每次 2～3 分钟，每天 1～2 次。」页面「健康调护与注意事项」中已有「穴位保健」一行，有内容即自动显示。
   HIS 方案的健康调护（`healthGuidance`）目前只有饮食、起居、情志、注意事项四项；若需要把穴位保健一并写回病历，需要在其中增加一个可选字段。这是本方案唯一涉及接口文档的地方（新增可选字段，不影响现有解析），请确认是否需要。
5. **验收。** 禁忌矩阵（妊娠阳性/可疑 × 每个禁用穴、各降级状态）0 违规；常见证候覆盖情况逐一列出；中医师抽检 20 例；页面与结构化结果（及开启后的 HIS）三处内容一致。
6. **工期与依赖。** 清单整理 1 天 + 中医师审定（外部依赖）；代码实现 1.5 天；验证 0.5 天。审定前不上线。

## 四、实施结果（2026-09-28）

### 4.1 穴位保健

- **清单**：`src/data/tcm-home-acupoint-care.source.json`，逐条保存技术规范原文（选穴、标准定位、操作、时长、次数、艾灸）与患者可读定位（按同身寸换算，如「肚脐正下方约四横指处」），每条带来源与审定状态。平和质、特禀质不对应任何证候病性，不收。
- **选穴**：由已确定的证候病性（受控病性词表）对应体质——先看本虚（阳虚 > 阴虚 > 气虚），再看标实（湿热 > 血瘀 > 气滞 > 痰湿）；外感（风、暑、毒）、动风、气脱与痰热不对应体质，不输出。例：脾胃气虚证 → 气海、关元（按揉，另可艾灸）；肝肾阴虚证 → 太溪、三阴交；膀胱湿热证 → 支沟、阴陵泉；风热犯肺证 → 不输出。
- **禁忌（比 2.3 更严的两处）**：① 妊娠阳性或可疑时整段不给（原方案只排除个别穴位）；② 育龄女性（10～59 岁）病历未写明是否妊娠时，去掉三阴交、合谷、昆仑、至阴及腹部、腰骶部穴位，并且不给艾灸。其余按 2.3：红旗、不出剂量的方案不给（参考剂量待复核的照常给——多半只是妊娠或用药细节未写，由上面的妊娠规则兜底）；3～17 岁、6 月龄以下不给；急性感染或炎症不给；发热、糖尿病或感觉减退、热象（舌红苔黄等）时不给艾灸，按揉照常。
- **启用状态**：清单每条仍标记为「待中医师审定」。按贵方 2026-09-28 确认，线上已用环境变量 `CDSS_HOME_ACUPOINT_CARE=include_pending` 先行启用（`off` 整体关闭，`approved_only` 只用已审定条目；改动不需要重新构建）。审定签字后把条目改为已审定，审定中如有修改以审定结果为准。
- **顺带修复**：中医外治项目的妊娠禁忌此前只读病历中的肯定句，「可能怀孕」这类可疑表述被过滤掉，针刺、艾灸项目卡照样推荐；现与妊娠阳性同样排除。
