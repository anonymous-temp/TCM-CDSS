## 4. 甲方其余问题

以下类别均已有确定性合同或数据治理闭环：性别必填、胃痛/腹痛急症边界、红旗命中依据、西医/中医术语隔离、诊断依据去重、中医鉴别、方证正向覆盖、随证加减来源和丢弃原因、未推药原因、健康调护、输出顺序、非药物项目参数权限。

输出注册表的 16 个医生可见合同现均声明 `rendererId`，并全部绑定到实际页面节点；回归会逐项检查合同 ID 与渲染器实现，不能再只登记表而不上屏。补齐的页面包括：

- 中医鉴别无法形成时的结构化边界说明；
- 学术流派适配及其安全让位说明；
- 管理与随访安全网；
- 方剂、煎服、随症加减、中成药/西药和 M05 审方的独立渲染节点；
- 非剂量路径中服务端 `## 当前结论` 的真实展示。

医生可见术语不再做无上下文的中文裸子串替换。`门控心肌灌注显像`、临床“病机关联”等合法表达保持原文；只有“门控未通过”“病机关联字段/校验/结果”等明确工程上下文才归一。`信息不足无法判断` 已登记到 T7 并替换为“受限结论 + 需要补充什么 + 何时复评”的可执行表述。

非药物治疗不再用硬编码穴位和频次填充空白：

- 只有适应证精确匹配且治理表存在完整参数模板时，才输出患者级受控参数。
- 未匹配模板时输出 `assessment_only_no_patient_specific_protocol`、明确缺口，且穴位/部位/频次为空。
- 即使参数完整也保持 `executable=false`，必须由医生确认；这不是空壳，而是对“无来源参数不得编造”的安全边界。

## 10. 自然语言闭集映射与医生确认

术语层不再靠不断追加别名维持召回，现为：

1. 精确受控词/唯一别名命中时直接返回；
2. 未命中时由确定性预筛把大词表压缩为有限候选；
3. `deepseek-v4-flash` 进行两次独立闭集选择，只能返回候选 ID 或弃权；
4. 服务端校验候选集、一致性和置信度，不合格即 fail-closed；
5. 归一文本和选择结果写入持久缓存；严格健康检查执行真实语义探针。

该层用于 T1-T4、T8、中成药概念和 ICD 召回；T9 饮片身份继续执行歧义即拒绝，禁止模型猜测替换。模型映射得到的主证候带 `resolvedBy`、候选和置信度溯源，未经医生确认不得把语义替换结果直接当成签名临床事实。确认接口校验当前 M03 的 HMAC、重新签名、使旧独立复核失效，并清除需重新生成的旧 M04，避免确认后仍沿用陈旧处方。

## 11. 红旗双层语义最终口径

红旗采用“确定性下界 ∪ 模型语义发现”的单调并集：

- T6 治理类目、限定条件、危险伴随和硬门条件注入语义模型；
- 模型负责口语、长句、否定、时序、主体和因果理解；
- 同一当前事件中的多条亚阈值线索可输出 `escalationRationale`，但必须附 2-6 条患者原文逐字证据；
- 任一证据无法落地、跨主体或跨时态拼接时，组合升级权限被剥离；
- 模型只能追加或升级提示，不能删除确定性红旗和危急生命体征结论；
- 稳定卒中后遗症等非急性背景不再因语义服务不可用而被通用叙事兜底误报，急性新发或加重仍由确定性层捕获。
