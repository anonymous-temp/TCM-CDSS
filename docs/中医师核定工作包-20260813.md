## 1.3 每一栏怎么填

- **主穴**：所有证型共用的基础取穴。要靠查体确定的照实写「局部阿是穴（查体确认）」——系统会把它归到操作边界，不会冒充成穴位。
- **加穴**：本证型在主穴之外**增加**的穴。
- **剔除穴**：本证型**不适用**的主穴（例：湿热证剔除关元）。没有就留空。
- **证据门槛**：只有病历里**确实记录了**这些事实之一，系统才自动应用这条加减；留空表示「证型名对上就应用」。您 0811 终审时明确要求风寒袭肺、痰湿中阻、肝肾亏虚三条必须带门槛，其余是否也需要请一并判断。
- **来源**：教材名 + 版次 / 指南名 + 年份 / 共识名。**没有可核验来源的条目我们不会录**——系统会把它标成「组合推导」并封顶权威等级，不会冒充教材依据。
- **年龄下限**：涉及胸背部深刺穴（中府、肺俞等）的模板请注明最低适用年龄。普通咳嗽模板您此前定的是 18 岁，8 个月婴儿实测已被正确挡在门外。

## 1.4 三条边界（不需要您决定，但请知悉）

1. **没签字的条目一律不启用**；系统照旧「如实标注、不冒充个体化」。
2. **加穴自动应用、剔除穴保守应用**：一条加减若未终审，它的加穴不生效、剔除穴仍生效（方向保守）。
3. **耳穴暂不做证型加减**：我们没有取得可核验的证型配穴权威来源；若您手上有，请一并提供。

# 任务三：方剂出处 → 流派归属终审（新任务）

## 背景

系统的「诊疗思路（流派）」选项目前只影响问诊与行文风格，**还没有影响候选方的排序**——需求基线要求它「实质影响候选方来源与排序」。做实的前提是一份您认可的「哪些方属于哪个流派取向」名单。我们从已生效的流派卡代表著作出发，按**方剂出处书名**机械推导了 204 首的归属，现请您终审。

## 签字后系统会怎么用（边界先说清）

医生选了某流派偏好时，已确认属于该取向的方剂，在**已通过全部安全与证据准入的候选池内**获得**有上限的排序加分**。三条硬边界：

1. **不放宽任何准入条件**——够不着候选资格的方，加分也进不来；
2. **不参与自动锁方判定**——系统按证据自动锁定哪张方，与流派加分无关；
3. **不改变剂量、禁忌、审方的任何校验**。不选流派时零影响。未签字的条目零影响。
