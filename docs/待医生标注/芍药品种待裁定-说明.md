# 芍药品种待裁定清单（共 34 首）

核定日期：待填　　生成日期：2026-08-09

## 为什么要裁定

赤芍与白芍**功效方向相反**——赤芍清热凉血散瘀，白芍养血敛阴柔肝。目录里裁定表自己写着：
> 猜错不是少给剂量而是**给反了药**。

品种定错的直接后果是**方名命不中**：处方写赤芍、目录记白芍，系统就认不出这是同一张方，
医生看到的是「本例辨证组方」而不是「犀角地黄汤加减」。

## 范围说明（先前口径有误，此处更正）

目录含芍药类方共 **521 首**，其中已裁定 116 首。剩余 405 首里：
- **380 首源文已写明品种**（白芍 207／赤芍 83／白芍药 52／赤芍药 30／炮制品 12）——不需裁定
- **24 首记的是裸「芍药」** → A 表，品种未定，必须裁定
- 另有 **10 首**目录已定品种、但与真实处方实测冲突 → B 表

既有 116 条裁定全部是解析裸「芍药」（芍药→白芍 93、芍药→赤芍 23），范围一直是这个口径。

## ⚠️ B 表怎么读（重要）

B 表是**「目录 vs 模型输出」的冲突，不是「目录 vs 古籍原文」的冲突**。
模型写错也会进这张表。所以它是**优先复核清单**，不是错误清单——
真正的判据只能是原书卷次。「我方初判」一列仅供参考，请以原文为准。
