## 关键校勘原则

1. 章节名不作为方名主记录；可以另存为章节索引。
2. 同名方使用‘方名 + 出处 + 月份/用途’生成唯一标识名，避免同名异方互相覆盖。
3. 组成优先按目标出处《外台秘要》本录入；《千金》《卫生家宝产科备要》等只用于断行补字和异文对照，不拿异本剂量覆盖本书。
4. 原书无专名者全部明确标为拟名，不能冒充古方专名。
5. 制法辅料不计入原文药味数；例如槐皮膏的猪脂是制膏基质，原文仍称‘上七味’。
6. 古方含野葛、附子、雄黄、胡粉等高风险/有毒历史药物，本文件仅用于古籍数据校勘，不构成现代临床处方。
