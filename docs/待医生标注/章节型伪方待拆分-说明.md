## 表怎么填

| 列 | 填法 |
|---|---|
| **是否章节题（是/否）** | 「是」= 确认是章节题、组成为多方合抄 → 我按你给的子方拆分入库；「否」= 它其实是一张真方 → 我恢复它的全部资格 |
| **应拆为哪些子方（方名＋卷次）** | 判「是」时填。格式同上批：`方名〔出处·卷次/用途〕`。不必给组成，我按你指的卷次回源；给了更好 |
| **备注** | 底本校异、异文、你觉得不该入现代候选池的（外治/剧毒/药材不可辨识）都写这里 |

**拿不准就留空。** 空着 = 维持现状（隔离），不影响系统安全性，只是少 1 条覆盖。填错会让一个拼出来的组成重新拿到开方资格。
