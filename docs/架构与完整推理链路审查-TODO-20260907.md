## 二、这次调整的产品方向

1. **结果价值优先。** 看主诉是否得到回应、推理是否说清、方药是否贴合、医生是否容易修改；完整字段数量和规则数量不作为成功指标。
2. **减少反复等待。** 一次整理可操作建议，优先局部完善，减少同一病例的整份重生成与反复复核。
3. **让知识帮助推理。** 把真正相关的方证、药味角色、指南段落送到模型面前，减少让模型猜、让系统事后删的来回。
4. **表达有分寸但有用。** 已有事实要用充分，合理推断说明依据，未知点自然说清楚；不因缺一项资料就把整份报告变成“待完善”。
5. **改善在后台比较。** 对照数据用于选择更好的实现，不新增医生操作步骤或内容输出的硬门槛；短时性能波动记录分布与影响，不凭单个样本阻断使用。

- 观察：每例追问数、重复问比例、医生跳过率、补录到更新的时间。
- 位置：`question/route.ts`、`m02-question-review.server.ts`、`m02-answer-interpreter.server.ts`。

### UX-14 · 优先 · 随访真正针对本例，并保持简短

- [ ] 给 M05 提供少量原始症状变化和生活背景，减少只根据证候名生成模板。
- 已见问题：`clinicalContextForAuthoring` 主要带主诉、证候、病机、治法和药味，完整病程/生活细节未必进入；prompt 却要求高度个性化，两者信息量不对等。
- 改法：选入影响随访的关键事实，按“何时复诊、看什么变化、日常怎么做”输出；页面先给 2–4 个重点，详细解释展开。同例在不同出口复用同一随访。
- 观察：不同病例内容的针对性、医生删改量、是否出现病历没有提供的生活假设、随访生成等待。
- 位置：[M05 上下文](/Users/wangzeyuan/Desktop/中医CDSS/src/lib/m05-followup-authoring.server.ts:100)。

### UX-15 · 优先 · 进度和提示语让医生知道下一步

- [ ] 合并重复提示，把工程状态改成具体动作与可继续操作。
- 改法：首个可用结论尽早展示；检索、生成、整理建议使用简短阶段说明。对未完成的次要段落显示“补充中”，有结果的区域继续可读/可编辑；可取消可选进一步分析，保留已经完成的部分。
- 加减继续保持动作、药味两列，触发症状和理由单独展示；选中后不再重复显示成“待加药”。
- 错误提示回答“哪部分没完成、现有结果还能做什么、点哪里继续”，不直接把 `unsupported_*` 或内部 reason code 甩给医生。
- 观察：第一份可用内容出现时间、空屏时长、取消/重复点击、提示语理解度。

### UX-16 · 优先 · 少花 Token、少做隐形重试

- [ ] 合并 SDK 与应用层重复传输重试，稳定前缀缓存，按一次病例计算真实成本。
- 已知证据：上一轮本地 503 模拟中 SDK 实际发 3 次请求，账本只记 1 次；这是等待与成本的问题，不需要新增临床门禁解决。
- 改法：统一重试执行与计数；将健康探针从临床业务成本分开；重复资料尽量复用，固定 prompt 段前置。缓存缺测如实标未取得，不把未知写成 0。
- 观察：每例实际请求数、输入/输出/缓存 Token、重生成率及费用；按并行关键路径解释耗时。后台观测失败不影响医生获取结果。
- 参考[SDK 重试配置](https://github.com/openai/openai-node/blob/main/docs/configuration.md)、[百炼上下文缓存](https://help.aliyun.com/zh/model-studio/context-cache)。

## 六、怎么比较改进，而不增加操作门槛

先处理 UX-01 的真实写回中断，同时推进 UX-02/04/16 的重复工作；随后把 UX-08/09/10 的知识和工具结果做精，再调整模型分工和复核方式。每次比较一个主要变量，保存改前改后的结果，避免同时改模型、prompt、检索后无法知道什么起作用。

对照用甲方原始病例形状及额外合成病例，关注：

| 体验问题 | 用什么读数帮助决策 |
|---|---|
| 医生等多久 | 首份可用内容、M03/M04/HIS 分别耗时、长尾和取消次数 |
| 输出是否有用 | 是否回应主诉、四诊是否被利用、诊断/治法/选方说明是否连贯 |
| 医生要改多少 | 修改次数、重录字段数、重复生成与追问次数 |
| 工具/知识有没有帮助 | 相关资料覆盖、实际引用/使用、无命中后恢复 |
| 复核值不值 | 提出的建议有多少被医生采用、改善了什么、额外等待多少 |
| 每例花多少 | 实际模型请求数、输入/输出、缓存和净费用 |

这些是后台产品观察与比较，不转成新的医生必填项或“一项未过就不输出”的条件。病位空集仍按用户决定作为轮间波动观察，不重开强制定位工作。
