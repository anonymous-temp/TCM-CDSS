## 3. 本轮发现并关闭的问题

1. 现代病例回放治理脚本存在未使用变量，导致 release lint 失败；已修复。
2. 回放资格重复生成时可能残留旧的 `replayEligible=true`；已改为每次从 false
   重新计算，并补齐毒剧药、单字药和剂量操作语料等全部闸门测试。
3. PostCSS 生产依赖安全告警；已由 `8.5.16` 升至 `8.5.23`，生产依赖审计为
   0 漏洞。
4. 线上临床事实抽取、裁决及 M03 复核回退仍存在 Flash 配置漂移；正式运行配置
   已统一为 `deepseek-v4-pro`。
5. Compose 未透传 `CDSS_MODEL_RATE_LIMIT_PER_10_MIN`，导致完整回归在第 61 个
   模型类请求后出现 429 级联失败；已补齐生产容器契约与防回归测试。
6. `seasonalCare` 回归仍断言旧的拼接字符串实现；已更新为结构化病性数组 +
   当前就诊日期契约。
