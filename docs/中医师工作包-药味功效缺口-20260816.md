# 中医师工作包：药味功效缺口终审（6 味）

2026-08-16。**这份只要 6 味的判断，其余已由系统自动完成。**

## 一、先说清楚这是干什么用的

系统给医生展示"方义"时，要说明每味药在本方里承担什么作用。做法是：把该药的**功效正文**（如"温中散寒，回阳救逆"）与本方治法比对，命中哪条就展示哪条。

如果库里只有**分类标签**（"消食药""平肝息风药"这种以"药"字结尾的章节名），比对必然落空，于是无论什么病例都只能显示兜底句"需医生结合方义复核"。这不是显示问题，是**这味药在方义栏永远是空的**。

695 味中原有 219 味处于这个状态。本轮已用国家药典委员会药典在线（ydz.chp.org.cn）自动补录 **152 味**，逐条 fail-closed 校验（药典词条标题必须与规范药名逐字一致、必须能切出"功能"段不混入"主治"、必须能映射到受控治法概念）。

**剩下需要人来判断的只有 6 味。** 另有 5 味是纯别名映射（败酱草→败酱、代赭石→赭石、朴硝/牙硝→芒硝、冬葵子→冬葵果），由工程侧完成，不劳烦医生。

## 三、给中医师的提示词（可直接粘贴给 AI 助手，或作为填写说明）

```
你是中药学与方剂学专家。请为下列药味给出**功效正文**，用于中医临床决策支持系统的方义展示。

【必须遵守的四条】
1. 只写「功能/功效」，**不要写主治**。
   正确：温中散寒，回阳救逆
   错误：温中散寒，用于脘腹冷痛、亡阳厥逆        ← "用于"之后是主治，不要写
   错误：收湿，生肌，敛疮，止血。外治溃疡不敛      ← "外治"之后也是主治，不要写
2. 用四字或三字的标准治法术语，逗号分隔，一般 2–6 条。
   参考写法：清热燥湿，泻火除蒸，解毒疗疮
3. **不要写「同某某」这类交叉引用**，请把功效展开写全。
4. 避免现代医学词汇（消炎、抗菌、镇痛、抗病毒等），改用中医治法术语
   （消炎→清热解毒 / 止痛→散寒止痛、活血止痛，按实际机理选）。

【每味请给出三项】
- 功效正文：
- 依据出处：（《中国药典》2020年版一部 / 全国统编教材《中药学》第X版 / 部颁标准 / 地方炮制规范，写到能复核的粒度）
- 备注：（若为炮制品或生熟有别，请说明与原药材功效的差异；若涉及毒性分级，请说明）

【本次待填药味】
1. 制草乌
   药典原文：「同草乌」（交叉引用）
   注意：制草乌与生草乌毒性档不同，请勿直接照抄草乌。
   若认为功效确与草乌一致，请明确写出"功效同草乌，但毒性与用法差异为……"。

2. 藏菖蒲
   药典原文：「温胃，消炎止痛」
   注意：请把"消炎"替换为对应的中医治法术语。

3. 虫白蜡
   注意：药典该条功能与主治无法机器切分，请直接给出功效部分。

4. 颠茄草
   注意：同上。本品为化学药源植物，若认为不宜纳入中药功效体系，请直接注明"不适用"。

5. 神曲（六神曲）
   现状：库内只有分类标签「消食药」，无功效正文。
   注意：本品为发酵品，2020年版药典一部未单列，请注明所依据的标准来源。

6. 炒麦芽
   现状：麦芽正文为「行气消食，健脾开胃，回乳消胀」。
   需回答：炒麦芽能否沿用？若不能，请给出炒制品的功效表述，
   并说明与生麦芽的侧重差异（临床上生麦芽疏肝回乳、炒麦芽消食，是否需在系统中区分）。
```

## 四、填好之后交给工程侧做什么

回填进受治理补充表 `src/data/tcm-herb-function-supplements.source.json`，每条需包含：

| 字段 | 说明 |
|---|---|
| `herb` | 药名（与库内规范名一致） |
| `supplement` | 功效正文（本工作包产出） |
| `basis` | 依据出处原文 |
| `sourceName` / `sourceUrl` | 出处名称与可复核链接（无在线源可留空并注明书名版次） |
| `missingConcept` | 由系统自动解析出的受控治法概念，无需填写 |
| `reviewBatch` | `CLINICIAN-REVIEW-20260816` |

回填后系统会自动：解析受控治法概念 → 校验不含主治语义 → 纳入方义比对。若某条因表述问题解析不通过，会退回并给出具体原因，不会静默丢弃。

## 五、口径说明（避免返工）

- **不必追求覆盖全部适应症**，方义展示只取"与本方治法对得上"的那一条，写全功效即可。
- **宁可少写不要多写**：多写一条不成立的功效，会让该药在不相干的方子里被错误地"解释"，比空着更危险。这一条与系统既有纪律一致（参苓白术散的桔梗曾被印成"祛痰排脓"，就是多写导致的）。
- **炮制品差异如果拿不准，请写"需区分"并说明疑虑**，系统会保留兜底句而不是猜测——空着不丢人，猜错才有风险。

### 一条退回项：藏菖蒲

裁定的「温胃，止痛」**无法进入受控治法词表**——实测该词表收
`温中 / 温里 / 温阳 / 散寒止痛 / 温经止痛 → yang_warm`，
但**不收「温胃」「暖胃」**，「止痛」单独也不成概念。因此这条功效正文进表后
无法参与任何方义匹配，等于空占一行，且会让回归闸门红。

按「宁可少写不要多写」的既有口径，本轮**暂不入表**（藏菖蒲语料用量为 0，无临床影响）。

**这不是裁定有问题，是受控治法词表缺词。** 请中医师确认下面这条：

> 「温胃」是否应作为「温中/温里」的同义治法收入受控治法词表（映射到 yang_warm）？
> 若是，「暖胃」是否一并收入？
>
> 注意爆炸半径：受控治法词表影响**所有**药味-治法匹配与方义展示，
> 不只是藏菖蒲一味。收词属治理层变更，需要终审而非工程侧自行决定。

确认后工程侧补词并回填藏菖蒲，无需医生再做第二次功效裁定。
